# Contributing to offline-ux-kit

Keep changes focused. For behavior changes, add a regression test that fails before the fix and passes afterward. Run `npm test`, `python scripts/validate_repository.py`, and the available Skill validator. Update generated `dist/` files and documentation when runtime behavior, installation, or validation changes.

Bug reports should include the browser or Agent runtime, operating system, exact reproduction steps, expected behavior, observed behavior, and relevant non-secret logs. Never attach real participant reports or private source data.
